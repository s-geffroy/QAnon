# Relectures editoriales

Rapports de l'API Editorial Reviewer (relecture multi-modeles, profil
`balanced`), produits par l'etape `editorial_review` du worker et copies ici
parce qu'ils expirent apres 24 h cote API. Un rapport juge la version du texte
indiquee par l'empreinte du nom de fichier ; les problemes sont des pistes, pas
des verdicts (`CONFIRMED` / `PROBABLE` / `UNRESOLVED` = degre d'accord entre
relecteurs).

Suites donnees (13/10/2026) :
- document de travail : ecart passe/avenir du test de l'horoscope teste (Fisher),
  continuite de l'actualite presentee comme hypothese, conclusion recalibree ;
  P1 et P6 (« un seul paragraphe ») venaient d'un defaut d'extraction du texte,
  corrige ; remarques de style (P3, P4, P7) non retenues.
- FAQ : serie PRRI decrite exactement, « Q citait parfois Trump », redite retiree.
- kit pedagogique : autocitations conformes a la mesure, taux de classe presente
  comme illustration, « une etude » (Levin) au lieu de « les etudes ».
- etat de la recherche : premiere revue en echec cote API (AbandonedJobError) ; resoumise a la demande du
  proprietaire : generalisation « la plupart des etudes » ramenee a la bibliographie du site (« a notre
  connaissance »), « citoyens souverains » et « expertise populiste » definis ; remarques de structure et de
  style laissees a la decision de l'auteur.
